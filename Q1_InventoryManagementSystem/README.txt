Q1 Inventory Management System
1. Run database.sql in MySQL Workbench.
2. Open this folder as a Maven project in IntelliJ.
3. In Main.java replace YOUR_MYSQL_PASSWORD with your MySQL root password.
4. Confirm URL port 3306 matches your MySQL server.
5. Run Main.java. Select menu option 1 to insert three sample records.
6. Test options 2 through 6.

If your MySQL port differs, update the URL. Do not upload your real database password to GitHub.
